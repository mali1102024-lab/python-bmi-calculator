# Python BMI Calculator

## Overview
This project is a Python-based BMI (Body Mass Index) calculator.  
It takes user input for **name**, **weight (lbs)**, and **height (inches)**, then calculates BMI using the formula:



\[
BMI = \frac{weight \times 703}{height^2}
\]

<img width="1229" height="767" alt="image" src="https://github.com/user-attachments/assets/bf1248fb-2b6a-40f0-bd2b-ff7fdd4b353f" />


The program outputs the BMI value and categorizes the result into standard health classifications.

---

## Features
- Accepts user input for name, weight, and height.
- Calculates BMI using the U.S. customary formula.
- Provides classification:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
  - Severely Obese
  - Morbidly Obese
- Prints personalized feedback messages.
